# DAR | Activos Digitales — Landing Page UI Kit

## Overview
High-fidelity interactive recreation of the DAR landing page. Built from the brand brief — no Figma or codebase was provided.

## Components
- `Nav.jsx` — Fixed navigation bar with logo, links, CTA button
- `Hero.jsx` — Full-viewport hero with headline, subtext, dual CTAs, abstract graphic
- `SocialProof.jsx` — Animated client name marquee
- `PainPoint.jsx` — "¿Software o Gasto?" pain section
- `Services.jsx` — Three-column service cards grid
- `Model.jsx` — Rent-to-own model highlight section
- `About.jsx` — Founder bio section
- `Footer.jsx` — Links, tagline, social

## Design Width
1440px desktop (responsive down to 375px mobile)

## Notes
- Fonts loaded from Google Fonts (Plus Jakarta Sans)
- Icons via Lucide (CDN)
- No real images — founder photo placeholder included
- All sections are scroll-animated with fade-up entrance
