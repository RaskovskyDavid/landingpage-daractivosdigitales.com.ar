# dar-sitio — paquete de traspaso a Claude Code

1. Descomprimí esta carpeta donde vas a crear el proyecto.
2. Abrila en Claude Code.
3. Pegá el contenido de `PROMPT-INICIAL.md` como primer mensaje.

| Archivo | Qué es |
|---|---|
| `CLAUDE.md` | La especificación completa: stack, rutas, sistema visual, animaciones, voz, honestidad, formulario, SEO, despliegue y lista de datos a completar. Claude Code la lee automáticamente. |
| `PROMPT-INICIAL.md` | El primer mensaje para arrancar, dividido en etapas. |
| `design/PortadaB.dc.html` | Diseño aprobado de la portada. |
| `design/referencia-version-a/` | Primeras versiones de servicios, blog y artículo: se usa su contenido, no su estilo. |
| `src/styles/tokens.css` | Colores, tipografía, radios, sombras y tiempos de animación. |
| `seo/jsonld-plantilla.json` | Marcado estructurado para buscadores (organización, persona y servicios). |
| `brief/BRIEF-DISENO-WEB.md` | Brief de referencia. |

Antes de publicar, completá los datos de la sección 8 de `CLAUDE.md`.
